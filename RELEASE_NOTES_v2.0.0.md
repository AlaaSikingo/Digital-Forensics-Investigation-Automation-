# DFIR-AI v2.0.0

V2 introduces the live local investigation dashboard and integrates the full evidence-to-report workflow into a visible, controllable case experience.

## Major additions

- Forensic image upload / existing-image selection
- Live case progress
- Stop Investigation
- Deterministic System and SAM telemetry
- Artifact inspector
- Correlation, clustering, and findings
- Bounded Qwen 4B / selective Qwen 8B analysis
- Historical DFIR RAG with evidence guardrails
- Deterministic synthesis
- Final DFIR Report V2
- 3-second sequential sidebar visualization

## Safety model

- Original evidence remains read-only.
- Current-case evidence is authoritative.
- Historical similarity is contextual only.
- AI output requires analyst validation.

**AI-assisted forensic investigation; analyst validation required. Original evidence remains read-only.**
